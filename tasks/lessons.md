# Lessons

- Do not promote a species-limited MHC gene to a broad ancestor node without
  checking the full descendant set that will inherit it at runtime.
- When a literature label looks numbered or clone-like, verify whether it is a
  canonical locus name before preserving it as ontology gene nomenclature.
- When citing regression coverage, distinguish raw-YAML cleanup tests from
  runtime inheritance tests and point to the file that actually covers each one.
